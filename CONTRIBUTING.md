# Como contribuir

## Preparação

1. Crie um fork e uma branch descritiva.
2. Instale as dependências com `npm install`.
3. Preserve os tokens e as regras do Brand Book.

## Antes de enviar

```bash
npm test
npm run build
```

Teste também em 360, 768 e 1440 px. Toda animação deve manter uma experiência equivalente quando `prefers-reduced-motion` estiver ativo.

## Pull request

Explique o problema resolvido, a decisão tomada e como a mudança foi verificada. Não inclua novos ativos de marca sem confirmar a licença de uso.
